This is the source for the zensical_recipes site, which documents various
hacks and customizations for the static site generator 
[Zensical](https://zensical.org/docs/). This is not a substitute for
Zensical's documentation and assumes familiarity with the official
documentation. Each recipe brings together a combination of custom CSS,
custom Markdown, custom templates, and custom code to accomplish things that
are not possible out-of-the-box.
